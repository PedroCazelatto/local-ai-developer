CUSTOMIZAÇÃO DE TERMINAL COM NODE.JS (FLUXO LINEAR E ALTA PERFORMANCE)
=====================================================================

Este documento resume como estruturar a interface do teu app de terminal em Node.js de forma leve, performática e integrada ao fluxo atual do terminal (sem abrir janelas ou limpar a tela), superando as limitações do Python (Rich).

1. AS BIBLIOTECAS IDEAIS (LEVES E DIRETAS)
-----------------------------------------
Para criar uma CLI moderna e interativa sem a complexidade de frameworks (como React/Ink), a melhor combinação no ecossistema Node.js é:

* @clack/prompts : Responsável pela interatividade (menus de setas, inputs de texto, validações) direto na linha de comando. Ele usa o fluxo nativo do terminal, mantendo o histórico visível ao rolar para cima.
* chalk          : Ferramenta padrão para colorir e estilizar textos (negrito, itálico, cores de fundo e suporte a RGB/Hex).
* ora            : Gerencia spinners (ícones de carregamento animados). Essencial para mostrar que o app está ativo enquanto o Ollama pensa ou o Docker executa algo.

2. VANTAGENS EM RELAÇÃO AO PYTHON (RICH)
----------------------------------------
* Performance Assíncrona: O Node.js lida com Entrada/Saída (I/O) de forma assíncrona por padrão. O terminal não trava ao gerenciar animações enquanto executa processos pesados (como chamadas de API ou comandos no Docker).
* Preservação do Histórico: Diferente de libs que controlam o buffer global da tela, o Clack apenas escreve linhas de texto estilizadas e captura comandos do teclado. O teu histórico de comandos continua no terminal.
* Estética Moderna Nativa: O Clack usa caracteres Unicode discretos que criam uma linha do tempo vertical conectando as etapas da conversa com a IA, dando um visual profissional e limpo.

3. EXEMPLO DE FLUXO INTERATIVO (AGENTE IA)
-----------------------------------------
O código abaixo exemplifica o comportamento sequencial usando async/await:

---------------------------------------------------------------------
import * as intro from '@clack/prompts';
import chalk from 'chalk';
import ora from 'ora';

async function main() {
  intro.intro(chalk.cyan('🤖 Agente Ollama Sandbox CLI'));

  // Menu de seleção com as setas do teclado
  const workspace = await intro.select({
    message: 'Selecione o workspace do Docker:',
    options: [
      { value: '~/projeto', label: 'Pasta Padrão (~/projeto)' },
      { value: 'custom', label: 'Digitar outro caminho...' }
    ]
  });

  // Entrada de texto para a IA
  const promptUsuario = await intro.text({
    message: 'O que a IA deve executar no workspace?',
    validate(value) { if (value.length === 0) return 'Digite um comando!'; }
  });

  // Spinner animado sem bloquear o terminal
  const spinner = ora('Ollama pensando...').start();
  await new Promise(r => setTimeout(r, 2000)); // Simulação
  spinner.succeed('Comando gerado!');

  // Confirmação Sim/Não
  const confirmar = await intro.confirm({
    message: 'Deseja executar esse comando no container seguro?'
  });

  intro.outro(chalk.cyan('✨ Processo finalizado!'));
}
---------------------------------------------------------------------
